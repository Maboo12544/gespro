# Lottery identity assets

Downloaded 2026-09-16 for identification in the existing POS lottery selector. Original branding belongs to each operator. No change to game rules, availability, schedules or payouts. Draw/session names remain visible to distinguish AM/PM and products sharing an operator. Custom unrecognized lotteries use initials rather than a falsely attributed logo.
